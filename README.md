# Travel Chronicles & Expeditions — Shashikant Prasad

Curated expedition masterplans, high-altitude trail logs, and field dispatches.
This is the Travel spoke of shashikantprasad.com (its own repository).

## Structure
- `index.html`: travel portal and expedition directory
- `meghalaya-blue-water-circuit.html`: 8-day Meghalaya masterplan
- `assets/css`, `assets/js`: shared travel styles and the lightbox/atlas engine

## Deployment
- Code deploys by GitHub Actions on push: `staging` -> `/staging/travel/`, `main` -> `/travel/`.
- Photos and videos are not stored in Git; they are uploaded directly to the server.
- The Hub main page lives in the photography repository, not here.
